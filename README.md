# SDM_seals_IP21
Author: Floris M. van Beest (flbe[at]ecos.au.dk)
Why: The below code was generated during the OBAMA-NEXT project to fulfil IP 21.
Reference: The code follows the analytical procedure described in the article: Galatius A, Teilmann J, Ahola, MP, Carlsson AM, Dietz R, Freitas C, Helle I, Jüssi I, Jüssi M, Kunnasranta M, Olsen MT, Carstensen J, van Beest FM (in press) Habitat suitability and distribution of harbour and grey seals in the Baltic Sea region. Marine Ecology Progress Series

Brief overview of code and data: The code reads the grey seal tracking data (based on ARGOS and GPS tags), formats the tracking data, and performs a habitat suitability analyses Raster data used in the analyses should be downloaded: van Beest, F. M. (2026). Raster data for SDM_seals_IP21. Zenodo. https://doi.org/10.5281/zenodo.20267043
